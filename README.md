# Codex Office Kit — macOS

Переносимый набор скиллов, Agency-ролей и локального Pixel Office. Для личного использования получателями этого приватного репозитория.

## Что входит

- 90 локальных скиллов; их исходные ограничения ручного запуска сохранены.
- 283 профиля Agency и экономный выбор специалистов: делегирование по пользе, полезные независимые задачи могут идти параллельно.
- Обновлённый Pixel Office: комнаты проектов Codex, реальные статусы агентов, задачи/календарь и настройка Telegram.
- Установщик с резервными копиями и автозапуском через macOS LaunchAgent.

Сам офис не вызывает модели. Установленная роль не означает запущенного агента. Задачи плана не запускаются автоматически; мониторинг процентов Vercel не подключён.

## Перед установкой

1. Установите Codex и войдите **в свой аккаунт**.
2. Нужны Git, Python 3.11+ и Node.js 22.12+ с npm. Проверка: `git --version`, `python3 --version`, `node --version`, `npm --version`.
3. Примите приглашение в приватный репозиторий на GitHub. На Mac доступен как Apple Silicon, так и Intel; Node/npm подберут зависимости для вашей архитектуры.

Установщик не устанавливает Homebrew, Python, Node, сторонние CLI или приложения и не включает доступ к вашим сервисам.

## Установка

```sh
git clone https://github.com/hamzaK228/codex-macos-setup.git
cd codex-macos-setup
./install.sh --dry-run
./install.sh
```

Перед запуском можно прочитать `install.sh` и `scripts/install.py`. Установка скачивает зависимости Pixel Office из npm по включённому lockfile и собирает интерфейс локально. Сторонние npm install-скрипты отключены; выполняются явные команды сборки из включённого исходного кода.

Только скиллы и профили, без офиса и hooks:

```sh
./install.sh --skills-only
```

Сборка и подготовка офиса без немедленного запуска (автозапуск начнётся при следующем входе в macOS):

```sh
./install.sh --no-start
```

Другие расположения поддерживаются через `--codex-home PATH` и `--install-root PATH`.

## После установки

1. Откройте настройки native hooks в Codex и **сами одобрите** добавленный локальный forwarder. Установщик не подменяет доверие и не отключает проверки.
2. Откройте новый чат Codex для обнаружения новых профилей. Доступность конкретных инструментов зависит от версии Codex и вашего аккаунта.
3. Откройте офис без копирования токена в переписку:

```sh
python3 "$HOME/.local/share/codex-office-kit/observer/open-office.py"
```

4. Начните задачу в проекте Codex: источник реальных событий появится в комнате. Сохранённые локальные проекты обнаруживаются по метаданным Codex; формат может зависеть от версии приложения.
5. Для Telegram: «Уведомления» → свой отдельный бот от @BotFather → код привязки личного чата → включить отправку → тест.

Ключи API, провайдеры, GitHub/Vercel/Supabase и другие плагины подключаются **к аккаунтам друга отдельно**. FreeLLMAPI-скилл включён, но сам роутер, провайдеры и секреты не установлены; он не станет работать без собственного подключения.

## Что меняется и где резервные копии

Скиллы и профили устанавливаются в `~/.codex/skills` и `~/.codex/agents`. В `~/.codex/AGENTS.md` заменяется только блок `codex-office-kit`, остальные инструкции сохраняются. В `hooks.json` добавляются записи forwarder, существующие записи сохраняются. Отличающиеся файлы копируются в `~/.codex/office-kit-backups/<дата-id>/` до замены.

Аккаунт Codex, `config.toml`, авторизация, чаты, проекты, ключи и Telegram-конфигурация отправителя отсутствуют. Новый локальный токен офиса создаётся на Mac; ранее существующие корректные token/config сохраняются.

Офис слушает только `127.0.0.1:4312`, не публикуется в интернете. Forwarder передаёт локально только метаданные жизненного цикла, без текстов запросов, ответов и файлов. По умолчанию наблюдаются проекты текущего пользователя во всех локальных папках; область можно сузить в `~/.config/pixel-agents-codex/config.json` (`scopes`).

## Обновление и остановка

```sh
git pull --ff-only
./install.sh
```

Изменённые настройки снова резервируются. Пользовательские данные офиса не входят в репозиторий. Чтобы остановить автозапуск:

```sh
launchctl bootout "gui/$(id -u)" "$HOME/Library/LaunchAgents/local.codex.pixel-office.plist"
```

Чтобы вернуть службу, повторите `./install.sh` или выполните `launchctl bootstrap` для этого plist. Для удаления пользовательских данных нет автоматического destructive uninstall; резервные копии остаются у вас.

## Состав и проверки

`snapshot.json` перечисляет скиллы/профили и исходный commit Pixel Agents. `THIRD_PARTY.md` сохраняет происхождение и ограничения сторонних материалов. Снимок включает исходники, а не аккаунты или кэш плагинов.

Проверки переносимости выполняются без реальных аккаунтов в временном HOME. Native LaunchAgent и окончательный запуск нужно подтвердить на настоящем Mac; этот экспорт подготовлен на Linux и не выдаётся за проверенный запуск на macOS.
